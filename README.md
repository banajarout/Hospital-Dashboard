Hospital Dashboard - Power BI

Project Overview

This project is an interactive Hospital Dashboard developed using Power BI. It provides insights into patient visits, waiting times, admissions, treatment duration, and department performance.

Tools Used

- Power BI
- Microsoft Excel
- DAX
- Data Modeling

Key Metrics

- Total Patients
- Average Waiting Time
- Admission Status
- Department-wise Analysis
- Severity Level Distribution
- Treatment Time Analysis

Dashboard Features

- Interactive filters and slicers
- KPI cards
- Pie and donut charts
- Line charts for trends
- Department performance analysis

Files Included

- Hospital_Dashboard.pbix
- Hospital_Data.xlsx
- Dashboard screenshots
